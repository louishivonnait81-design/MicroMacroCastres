# MicroMacro-Castres

Carte isométrique noir et blanc d'un vieux Castres réinventé, façon MicroMacro.

- `SQUELETTE.md` — le plan complet, phases et portes de validation
- `DECISIONS.md` — ce qui est fixé (format, échelles, périmètre, monuments)
- `STYLE.md` — kit pour les générations Gemini (phases 4–5)
- `PROMPT_CLAUDE_CODE.md` — les messages à envoyer à Claude Code
- `tasks/` — une fiche par étape, dans l'ordre
- `pipeline/` — scripts (Blender = module Python `bpy`)
- `tools/` — micro-outils web (éditeur de grille, placeur)
- `library/` — SVG des monuments, détails, personnages + catalogue
- `layers/` — placements ; `cases/` — enquêtes ; `inbox/` — images brutes venant de Gemini
